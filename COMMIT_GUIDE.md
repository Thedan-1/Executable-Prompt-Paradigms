# 可直接上传 GitHub 的版本化提交信息

下面是一组适合直接照着提交的 Conventional Commits 文案：

1. `chore: init repository scaffold`
2. `docs: add chinese repository overview`
3. `feat: implement structured output demo`
4. `feat: implement self-consistency reasoning demo`
5. `feat: implement react tool loop demo`
6. `feat: implement reflection repair demo`
7. `feat: implement guardrails defense demo`
8. `docs: add blog and screenshot traces`
9. `docs: add project structure guide`
10. `chore: add license and gitignore`

如果你打算按版本发布，可以这样打标签：

- `v0.1.0`：仓库骨架和基础示例
- `v0.2.0`：加入中文深度文档与博客
- `v0.3.0`：补齐截图、结构说明与提交指南
